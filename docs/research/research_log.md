## Preliminary research conclusion

The reviewed sources show that hotel reservation management involves room availability, guest information, booking cancellations, payments and operational reporting.

The proposed project will develop an Oracle database application using PL/SQL to manage these activities and prevent double booking. A Python Streamlit dashboard will provide an interactive interface for viewing reservation information and hotel performance.
